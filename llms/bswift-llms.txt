## What an agent can and cannot do here

bswift runs a live production API gateway at `https://api.bswift.com`. It is reachable —
`GET https://api.bswift.com/ping` returns `200 healthy` — but **every functional route
requires partner credentials** and answers `MISSING_AUTHENTICATION_TOKEN` without them.
There is no public developer portal, no API reference, no OpenAPI document, no sandbox
and no webhook catalog at any public URL. API access is issued through the alliance /
integration / channel partner programs.

An agent cannot integrate with bswift from public information alone. It can research
bswift's connectivity posture, security and compliance posture, and product release
history.
